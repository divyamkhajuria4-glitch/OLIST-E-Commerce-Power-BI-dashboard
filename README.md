📊 **OLIST E-Commerce 360° Sales, Profit & Business Intelligence Dashboard | Power BI**

I built an end-to-end **Power BI E-Commerce Analytics Dashboard** using the Brazilian Olist E-Commerce dataset (2016–2018), containing **99K+ orders**.

The goal was to transform raw transactional data into a business-focused dashboard covering **revenue, profitability, customers, products, logistics, and time-based sales performance**.

🔧 **What I worked on:**
• Imported and transformed 9 Olist CSV datasets using Power Query
• Cleaned data types, nulls, and duplicates
• Built relationships and a structured data model
• Created a dedicated **DimDate table with 1,095 dates**
• Developed DAX measures for Revenue, Orders, Profitability and AOV
• Built **7 interactive dashboard pages** with 30+ visuals
• Added slicers, charts, KPI cards, geographic analysis and trend analysis
• Performed business-focused analysis instead of only creating visualizations

📑 **Dashboard Pages:**

1. Executive Overview
2. Profitability
3. Revenue By Customer
4. Sales Performance
5. Product Category Analysis
6. Logistics
7. Time Analysis

📈 **Key Insights:**
• São Paulo contributes approximately **42% of total revenue**
• Health & Beauty and Watches & Gifts are among the strongest categories from a profitability perspective
• Order activity is strongest during the **2 PM–10 PM** period
• Delivery delays exceeding 7 days are **associated with lower customer review scores**, highlighting a potential logistics/customer-satisfaction issue

🛠️ **Tools & Skills:**
Power BI | Power Query | DAX | Data Modeling | Data Cleaning | Data Visualization | Time Analysis | E-Commerce Analytics | Business Intelligence

This project helped me practice the complete BI workflow:

**Raw Data → Power Query → Data Model → DAX → Dashboard → Business Insights**

The objective was not just to build a dashboard, but to understand **what the data is saying and how those insights could support business decisions.**
